# 工资到账对账实施计划

**Goal:** 原提交数量保留，不合格数量按记录单价扣减；月底手动确认全勤奖 100 元；按工资所属月登记分次到账。
**Architecture:** 沿用 SQLite/FastAPI 和现有页面。扣件按交件 ID 保存累计数量及原因；全勤奖按月保存确认结果；到账使用客户端请求 ID 防止重试重复入账。
**Spec:** 本聊天已确认的扣件规则及手动全勤奖方案。

- [x] 浏览器验证页面操作并更新说明。所有验证使用临时账本，不部署、不提交已有改动。

全勤确认不由出勤记录推断，月底（含最后一天）及以后才可确认；未确认暂计 0 元并显示提示。到账金额精确到分，作废保留日志和备份。旧备份缺少新增表时按空表恢复。
