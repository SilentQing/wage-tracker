# Daily Attendance Implementation Plan

**Goal:** 每天 8.5 小时，无周休日，截至今天默认出勤，只记录请假。
**Architecture:** 每月显式启用日历考勤，保留旧月度数据；请假独立存储，结算时冻结统计截止日。沿用 FastAPI、SQLite、原生 JS。
**Spec:** 用户在本聊天确认的每日 8.5 小时及默认出勤规则。

- [x] 后端：新增每日考勤月份及请假表，提供启用月份、请假保存接口；半天 4.25 小时，未来日期拒绝，锁定月份拒绝修改。
- [x] 核算：正班工时为已过日历天数 × 8.5 减请假小时；出勤天数按 8.5 小时折算。旧月份仍采用原算法。
- [x] 页面：出勤日历、全天/半天/自定义请假、清除请假；自动模式禁用手填出勤。
- [x] 备份：包含新增表，兼容旧备份，恢复校验日期与引用。
- [x] 验证：默认出勤、请假、跨月、锁定冻结、旧数据兼容、备份恢复回归；JS 语法检查。

验证记录：2026-11-08，`.venv/Scripts/python.exe -m unittest discover -s tests -v` 30 项通过（退出码 0）；`node --check static/app.js` 通过。未做浏览器实机验证或生产部署。

未来月份不提前累计；当月中途结算冻结截止日期；解锁恢复动态计算。既有月份需点击启用以免静默改账。新增月份同样可一键启用，之后只需记请假。
